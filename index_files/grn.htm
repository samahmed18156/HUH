Receiving Stock.

 

Step 1: Select the Creditors Menu option on the Menu line.

 

 

 

 

 

 

 

Select Creditors GRN / Invoice

 

 

 

 

 

 

 

 

 

 

Step 2: Enter a valid creditors account no or select <F2> to search for a valid creditor.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Thereafter enter a valid date that the goods were received, the invoice no from the supplier and then check the Vat Incl box. This must only be checked if the suppliers price includes VAT in the price. Most suppliers add VAT at the end (vat excl) in their selling prices.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Step 3: Enter a stock code or selct <F2> to search by a stock code and <F3> to search by stock description.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Step 4: Enter the quantity received and the price. If  the value is entered the unit price will be calculated depending on the quantity entered. The Edit Prices must be checked before the stock item is scanned if the selling price needs to be updated.

 

 

 

 

 

 

 

 

Press enter on each of the Selling Prices to view the latest GP%.

Select <F12> to complete GRN, the option to print the GRN is also given.
