Creditors Debit Note (Return stock to supplier).

 

Step 1: Enter a valid creditors account no or select <F2> to search for a valid creditor.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Thereafter enter a valid date that the goods are returned to the supplier and the invoice no. Check the Vat Incl box. This must only be checked if the suppliers price includes VAT in the price. Most suppliers add VAT at the end (vat excl) in their selling prices

 

Step 2: Enter a stock code or selct <F2> to search by a stock code and <F3> to search by stock description.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Enter the quantity to be returned and the price. If  the value is entered the unit price will be calculated depending on the quantity to be returned.

Select <F12> to complete Debit Note, with the option to print the Debit Note
