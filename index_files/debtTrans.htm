Creating Debtor’s Transactions (eg Payments, Discount, Journals, R/D Cheques):

 

Select the Debtors menu option thereafter select Debtors Transactions

 

 

 

 

 

 

 

 

 

 

Enter the debtors account no or leave it blank to display all the debtors.The option is given to search by Account Num, Name

Telephone No or Area.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Select the account no to process transactions against.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Select the type of transaction to be processed, thereafter enter the amount. The Age and Payment type can also be changed. The debtors account age is from Current Bal (current month until 330 Days) so any payment may be allocated to a specific age.
