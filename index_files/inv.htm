Invoicing: Cash Sales/Account Sales

 

Select the Debtors option on the menu line and thereafter select Invoicing.

 

 

 

 

 

The system automatically defaults to the CASH account. If another account needs to be entered then delete the CASH account and select <F3> to search for a particular debtor.

The option to enter the Agent No, Order No and Delivery Address is given depending on the setup for the user.

 

Scan the item to be sold or select <F2> to search for a particular stock item. The option to change the selling price and quantity depends on the setup of the user.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

If the stock code that is been sold has sizes then either scan the barcode or enter the stock code and a pop-up displaying all the available sizes will be displayed. Select the correct size to continue with the sale.

 

 

 

 

 

 

 

 

 

 

 

Select <F12> to End the Sale

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Enter the correct tender type and select <DONE> to complete the sale. The Change displayed and press <DONE> to continue with the next sale.

 

 

If the sale is a laybye sale then select the tender type, thereafter enter the payment received for the laybye.

Enter the contact details of the person making the laybye, the system will automatically create a laybye no. Select <Done> when complete.
