Linked Codes:

 

 

 

 

 

 

 

 

 

 

Linked codes are used when you have more than one item you wish to sell as a single item eg; food hampers etc.

 

The stock items that make up the hamper must be created prior to be able to use Linked Codes.

 

Step 1: Add the stock item called “Hamper”.

 

Step 2: Highlight “Hamper”, click details and the select the Linked Codes tab as shown above.

 

Step 3: Enable Links

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Thereafter add all the items that make up the  “Hamper”. There is no restriction as to the number of items that make up the hamper.
