Stock Adjustments

Step 1: Select the Adjustments Menu option on the Menu line. Thereafter select Stock Adjustment.

 

 

 

 

 

 

 

 

 

 

 

Step 2:

Enter a valid stock code or select <F3> to search for the relevant stock code that must be adjusted. Select Stock In if stock must be added or Stock Out to deduct stock from the Quantity on Hand.

Select Done when completed.
