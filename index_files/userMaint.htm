Adding users and changing the users access profile.

 

Select Utility and then User Maintenance.

 

 

 

 

 

 

 

 

 

 

If a new user must be added then select an existing user and select add. Add the user id, name, surname, password and the password again to confirm the password.

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

 

Select the Menu that the user must have access eg Stock Menu, Creditors Menu etc.

Thereafter select the type of access the user must have.

Select <Save> when completed, the menu options the user will see when logging on will depend on the access given.
