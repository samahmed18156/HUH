IBT menu option.

 

The IBT option allows the user the ability to create on-line   invoices for debtors. The debtor can then automatically load the invoice into MiPOS without capturing a GRN.

The process is as follows:

           1. At head office create an invoice.

           2. Create IBT for store.

           3. At the store Load IBT (this will automatically create                new stock items and update the stock on hand for                existing stock items and change cost and selling                prices if they have changed).

To be able to use this option there are certain functions that has to be setup, please contact MiCOMP to have them setup.
